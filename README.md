# QuickCommerce 🛒

QuickCommerce is a responsive frontend e-commerce website project built using HTML, CSS, and JavaScript.  
It includes a homepage, electronics section, responsive product cards, navigation menus, interactive buttons, and modern UI styling.

---

## 🚀 Features

- Responsive e-commerce UI
- Homepage with hero slider
- Electronics product page
- Product cards with pricing and ratings
- Add to Cart button interaction
- Sticky navigation bar
- Modern responsive design
- Mobile-friendly layout
- Font Awesome icons integration
- Google Fonts support
